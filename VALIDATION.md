## Still requires a real phone

1. Installation and launch on the target Android device.
2. Simultaneous touch steering and throttle, screen cutouts, and comfortable tap targets.
3. Ramps, uneven ground, asymmetric ballast, and recovery.
4. Background / resume behavior and save persistence after closing the app.
5. Sustained FPS, temperature, and battery use.

The screenshot runner uses software rendering, so its FPS is not a phone-performance benchmark. The 96-part limit is a design guard, not a measured hardware guarantee. No physical Android device or Android emulator was accessed during this build.

The first export attempt failed because Android texture import was disabled. Enabling ETC2 / ASTC imports fixed that export requirement. The GitHub workflow is configured to stop on script errors, failed engine checks, or a failed APK signature check.
